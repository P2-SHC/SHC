## 1. App.jsx 라우팅 상태

```
┌──────────────────────────────────────────────────┐
│                    App.jsx                        │
│                                                  │
│  page            현재 페이지명                    │
│  category        게시판 카테고리                  │
│  selectedPostId  게시글 상세 ID                   │
│  productId       상품 상세 ID                     │
│  from            돌아가기 분기용 출처 페이지       │
│  fromPostId      돌아가기 분기용 게시글 ID         │
│  healthSavedState  AI 추천 결과 보존              │
│  orderItems      결제 페이지 전달용 주문 배열      │
│  fromCart        결제 출처 (장바구니 여부)         │
│  weatherIcon     날씨 아이콘 코드                 │
└────────────────────┬─────────────────────────────┘
                     │ navigate(pageName, params)
          ┌──────────┼──────────┐
          ▼          ▼          ▼
       [Pages]   [Header]  [AlarmNotifier]
```

## 3. localStorage 키 맵

```
localStorage
│
├── [전역 - 계정 무관]
│   ├── shc_users                          →  User[]
│   ├── shc_current_user                   →  User  (passwordHash 제외)
│   ├── shc_products                       →  Product[]
│   └── shc_font_scale                     →  "small" | "default" | "large"
│
└── [사용자별 - {username} = 로그인 계정명]
    ├── shc_cart_{username}                 →  CartItem[]
    ├── shc_medicines_{username}            →  Medicine[]
    ├── shc_blood_sugar_{username}          →  TimeAlarm[]
    ├── shc_blood_pressure_{username}       →  TimeAlarm[]
    └── shc_alarm_fired_{username}_{날짜}   →  string[]  (fireKey 집합)
```

## 4. 주요 데이터 타입

```
User
├── username         : string
├── name             : string
├── passwordHash     : string    ← shc_users 전용 (current_user엔 없음)
├── age?             : number
└── healthInterests? : string[]


Product  (product.json / shc_products)
├── id          : number
├── category    : "recipe" | "exercise" | "life"
├── title       : string
├── keyword     : string[]
├── description : string
├── price       : number
├── quantity    : number         ← 재고 수량
└── image       : string


CartItem  (shc_cart_*)
└── ...Product
    └── quantity : number        ← 장바구니 담은 수량 (재고 아님)


Article  (articleData.json)
├── id        : number
├── category  : "recipe" | "exercise" | "life"
├── title     : string
├── keyword   : string[]
├── content   : string           ← 마크다운
├── createdAt : "YYYY-MM-DD"
└── viewCount : number


Medicine  (shc_medicines_*)
├── id             : string      ← 랜덤 생성
├── name           : string
├── dosage         : string
├── alarmTimes     : string[]    ← ["08:00", "20:00"]
├── totalCount     : number | null
└── remainingCount : number | null


TimeAlarm  (shc_blood_sugar_*, shc_blood_pressure_*)
├── id   : string
└── time : string                ← "HH:MM"
```

## 5. 결제 데이터 흐름

```
ProductDetailPage                    CartPage
│                                    │
│  { ...product,                     │  selectedItems
│    quantity: selectedQty }         │  (체크된 CartItem[])
│  fromCart: false                   │  fromCart: true
│                                    │
└────────────────┬───────────────────┘
                 │ navigate('CheckoutPage', { orderItems, fromCart })
                 ▼
           CheckoutPage
           │
           ├── orderItems : CartItem[]
           ├── fromCart   : boolean
           │
           ├── Step 1.  getStock(id) 전체 상품 선검증
           │            재고 부족 시 → alert 후 중단
           │
           ├── Step 2.  decreaseStock(id, qty) 일괄 차감
           │
           ├── Step 3.  fromCart === true → removeFromCart()
           │
           └── Step 4.  navigate('MainPage')
```

## 6. 알람 시스템 흐름

```
AlarmContext
├── medicines[]
├── bloodSugarAlarms[]
└── bloodPressureAlarms[]
         │
         │  useRef로 최신값 동기화 (stale closure 방지)
         ▼
AlarmNotifier  (앱 전역, 항상 렌더)
│
├── setInterval(checkAlarms, 30_000ms)
│   │
│   ├── 현재 HH:MM  ==  alarmTime ?
│   │        │
│   │        └── firedRef에 없으면
│   │               ├── firedRef에 추가
│   │               ├── localStorage 저장
│   │               └── pendingAlarms에 push
│   │
│   └── (이미 firedRef에 있으면 무시 → 중복 방지)
│
└── pendingAlarms[]  (큐)
    ├── [0]  →  모달 팝업 표시
    ├── [1~N]   "+N개 대기 중" 표시
    │
    └── 확인 클릭
        ├── type === 'medicine'  →  decreaseMedicineCount()
        └── pendingAlarms[0] 제거  →  다음 알람 자동 표시
```

## 7. 추천 알고리즘 구조

```
[메인 인기글]

articles[]
└── sort( 날짜 근접도 + 조회수 × 86,400,000 )
    └── [0]  →  피처링 게시글 1개


─────────────────────────────────────────────────

[게시글 상세 상품 추천]

products[]
└── map  →  matchCount = |상품 keyword ∩ 게시글 keyword|
         │
         ├── category == "life"
         │   └── matchCount 내림차순 → 상위 3개
         │
         └── category == "recipe" | "exercise"
             ├── preferred : 같은 category + matchCount > 0
             └── others    : 다른 category + matchCount > 0
                 └── [...preferred, ...others].slice(0, 3)


─────────────────────────────────────────────────

[위젯 상품 추천]

weatherIcon 앞 2자리
├── "01"          →  키워드: "자외선"
├── "09","10","11" →  키워드: "비"
├── "13"          →  키워드: "눈"
└── 그 외          →  키워드: "환절기"
         │
         ├── "미세먼지" 키워드 pool → 랜덤 1개
         │   (없으면 전체 상품 랜덤)
         │
         └── 날씨 키워드 pool → 랜덤 2개
             (부족하면 나머지 상품으로 보충)
             └── 최종 총 3개 추천


─────────────────────────────────────────────────

[AI 건강 추천]

프롬프트 입력
├── 사용자 건강 키워드 (다중 선택)
├── 자유 텍스트 입력
├── 사이트 내 상품 목록 전체
└── 사이트 내 게시글 목록 전체

규칙
├── 관련성 높은 것만 엄선
├── 개수 강제 없음 (1~4개)
└── 목록 외 추천 금지 (프롬프트 어택 방지)

응답 파싱
└── JSON { productIds[], posts[{ category, id }], comment }
    └── literal 줄바꿈 sanitize 후 JSON.parse
```

## 8. 전체 데이터 흐름 요약

```
사용자
  │
  ▼
App.jsx (navigate로 페이지 전환)
  │
  ├── Context API (전역 상태)
  │   ├── UserContext   ↔  shc_users / shc_current_user
  │   ├── CartContext   ↔  shc_cart_{username}
  │   ├── ProductContext ↔ shc_products
  │   ├── AlarmContext  ↔  shc_medicines / blood_sugar / blood_pressure
  │   └── FontSizeContext ↔ shc_font_scale
  │
  ├── 외부 API
  │   ├── geo.ipify.org  →  { lat, lng }
  │   │       └──▶ OpenWeatherMap  →  날씨 + weatherIcon
  │   │       └──▶ WAQI            →  미세먼지 AQI
  │   └── Claude AI  →  맞춤 추천 JSON
  │
  └── 페이지 간 데이터 전달
      ├── ProductDetailPage / CartPage  →  CheckoutPage (orderItems)
      ├── HealthRecommendPage  →  App.jsx (healthSavedState 보존)
      └── BoardDetailPage  →  ProductDetailPage (from, fromPostId)
```
